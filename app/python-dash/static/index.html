Slider modes
Master volume — sets the system volume.
App volume — sets volume for the listed apps (exe names, e.g. spotify.exe). Leave empty = master.
Monitor brightness — sets brightness of the chosen monitor (or all).
None — ignored.

Calibration — your board reads ~888 at 0% and 0 at 100%, so sliders default to inverted with range 0–888. Auto-cal widens the range as you move; or use Capture min/max with a slider parked at each end.

Macro pad — each button fires on press or release with one action, or pick Multi-step sequence to build a macro from steps (+ Add step), reorder with ▲▼, and record key combos with ⏺. Steps run top to bottom: 
combo: ctrl+alt+t  →send keys   delay: 0.2  →wait   text: hello
launch: notepad   →start app   media: play →media key   mute / brightness_up: 10
Everything saves to config.json.
