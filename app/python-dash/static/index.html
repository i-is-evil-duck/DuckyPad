Slider modes
Master volume — sets the system volume.
App volume — sets volume for the listed apps (exe names, e.g. spotify.exe). Add some with the input below the chips. Leave empty = master.
Monitor brightness — sets brightness of the chosen monitor (or all).
None — ignored.

Operation — your board reads ~888 at 0% and 0 at 100%, so sliders default to inverted with calibration 0–888. Auto-cal watches the raw values and extends the range, or use the capture buttons: put a slider at its bottom, press Capture min, top → Capture max.

Macros — each pad button can fire a combo (ctrl+shift+s), typed text, a media key, launch a program, master mute, brightness nudge, or a sequence of steps (one per line): 
combo: ctrl+alt+t
delay: 0.2
text: hello world
launch: notepad
media: play
brightness_up: 10
Everything saves to config.json — press Save (or it auto-saves while calibrating).
